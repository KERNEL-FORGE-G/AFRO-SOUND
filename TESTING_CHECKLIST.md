# 🧪 Checklist de Test - AFRO SOUND Premium & Téléchargement

## ✅ Avant de Commencer

## 🎯 Test 1 : Interface Premium

### Navigation vers Premium
- [ ] Aller à Home screen
- [ ] Voir la section "Débloquez l'expérience complète" en or
- [ ] Cliquer sur le bouton Premium
- [ ] Accéder à l'écran Premium

### Écran Premium
- [ ] Vérifier le titre "Débloquez toute la musique"
- [ ] Voir les 6 avantages listés (téléchargements, pas de pubs, etc.)
- [ ] Voir 3 plans : Mensuel, Annuel, Famille
- [ ] Cliquer sur chaque plan pour sélectionner
- [ ] Voir le badge "Meilleure valeur" sur plan annuel
- [ ] Voir le bouton "Essai gratuit de 7 jours"
- [ ] Lire les termes d'utilisation
- [ ] Revenir en arrière

### Profil Premium
- [ ] Aller à Profile screen
- [ ] Voir la carte "Passer à Premium" en haut
- [ ] Cliquer sur "Découvrir Premium"
- [ ] Accéder à l'écran Premium

## 📥 Test 2 : Téléchargement

### Sur MusicPage
- [ ] Aller à une playlist quelconque
- [ ] Voir les morceaux avec leurs actions
- [ ] Voir l'icône cloud download (2e bouton)
- [ ] Cliquer sur le bouton téléchargement
- [ ] Voir la progression 0-100%
- [ ] Attendre la fin du téléchargement
- [ ] Voir "Succès" + nom du morceau

### Vérifier les Fichiers (Android)
- [ ] Ouvrir DownloadManager (ou fichiers)
- [ ] Vérifier que le fichier est dans Downloads
- [ ] Vérifier la taille du fichier
- [ ] Écouter le fichier téléchargé

### Sur Now Playing
- [ ] Jouer une chanson
- [ ] Voir les actions en bas
- [ ] Voir l'icône download dans les actions
- [ ] Cliquer pour télécharger
- [ ] Vérifier la progression

## ⚠️ Test 5 : Gestion d'Erreurs

### Pas de Connexion
- [ ] Déactiver WiFi/Mobile
- [ ] Essayer de télécharger
- [ ] Voir message d'erreur approprié
- [ ] Réactiver connexion

### Espace Disque Faible
- [ ] Vérifier espace disque
- [ ] Si <100MB, essayer téléchargement
- [ ] Voir handling d'erreur
- [ ] Libérer espace et réessayer

### Téléchargement Dupliqué
- [ ] Télécharger un morceau
- [ ] Cliquer encore sur download (rapidement)
- [ ] Voir "Déjà en cours"
- [ ] Pas de double téléchargement
